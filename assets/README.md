**올리는 법 (git 없이):** GitHub 웹에서 폴더를 열고 **Add file → Upload files** 로
끌어다 놓으면 된다. 여러 장을 한 번에 올릴 수 있다.

작품 사진은 가로 1600~2400px · JPEG 82~88% 면 충분하다.
히어로는 화면을 가득 채우므로 **가로 2400px 이상**을 권한다.
